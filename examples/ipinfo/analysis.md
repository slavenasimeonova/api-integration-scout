## Risks

- **MEDIUM**: Two response schemas. Updated (api.ipinfo.io) and legacy (ipinfo.io) shapes differ (nested geo/as vs flat city/loc); pick one deliberately.
- **MEDIUM**: Token in query string. The token is commonly shown as a query parameter, which can leak into logs; prefer the Bearer header server-side.
- **MEDIUM**: Error format undocumented. The fetched pages don't describe error bodies; only 429 and 'error on free tokens' are mentioned.
- **LOW**: Tier gating. /lookup is paid-only; free tokens must use /lite.
- **LOW**: Batch size. Batches are limited to 1,000 items per request.
