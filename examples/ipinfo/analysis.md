## Risks

- **MEDIUM**: Two response schemas. The new api.ipinfo.io schema (nested geo/as) differs from the legacy ipinfo.io schema (flat city/loc, asn object). Privacy Extended data is only on the legacy route. Choose one deliberately.
- **MEDIUM**: Error format undocumented. The pages fetched give no error body schema. Only a 429 on quota exhaustion is mentioned. Free tokens calling /lookup get an error whose shape is unspecified.
- **MEDIUM**: Token exposure. The token is commonly passed as a query parameter, which can leak into logs. Use the Bearer header on the server side. JSONP and CORS client-side use would expose the token.
- **LOW**: Tier-gated endpoints. /lookup and most batch patterns need a paid plan. Lite is free but returns only country and ASN data.
- **LOW**: Monthly quota and overage billing. Hitting the quota returns 429 unless metered billing is on, in which case overages are billed.
